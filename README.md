## 📖 Introduction | 项目介绍
### English
A high-precision Lorentz factor calculator implemented with Python.
It calculates the Lorentz factor γ in special relativity and supports arbitrary high decimal precision output.
Packaged as a native Windows installer. End users do not need to install Python runtime manually.

### 中文
使用 Python 实现的洛伦兹因子高精度计算器。
用于求解狭义相对论中的洛伦兹因子 γ，支持极高精度小数输出。
已编译为原生 Windows 安装程序，终端用户无需手动部署 Python 运行环境。
